How Code Stacker works

  1. Players take turns at one keyboard.
  2. Your turn: write exactly one line of JavaScript.
  3. The whole file is executed before the turn passes.
  4. If it runs, the line locks. Next player.
  5. If it errors, you stay and fix that same line.
  6. Three failed runs or the timer hitting zero and you are out.
  7. When spec tests go green, you shipped.
